This is an example post written in **MDX**. You can use Markdown and JSX in the same file.

## Adding new posts

1. Create a new `.mdx` file in `content/thoughts/`.
2. Add frontmatter at the top:

```yaml
---
title: "Your Post Title"
excerpt: "A short summary for listings and SEO."
date: "2025-02-24"
author: "Your Name"
tags: ["tag1", "tag2"]
---
```

3. Write your content below the frontmatter. The post will appear on the Thoughts index and at `/thoughts/your-filename` (without `.mdx`).

## Styling

The layout uses Tailwind's typography plugin styles via `prose` classes. You can customize the look in the post page component or in `globals.css`.

Happy writing!
